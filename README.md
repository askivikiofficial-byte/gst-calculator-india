# GST Calculator India 🇮🇳

A simple GST Calculator for India that helps users calculate GST-inclusive and GST-exclusive amounts instantly.

## Features

* GST Exclusive Calculation
* GST Inclusive Calculation
* Supports 5%, 12%, 18%, and 28% GST rates
* Mobile-friendly design
* Fast and easy to use

## Technologies Used

* HTML
* CSS
* Bootstrap 5
* JavaScript
